# 🚀  Project Report Generator

A modern AI-powered Project Report Generator built using **Python**, **Streamlit**, and **Google Gemini AI**.

## ✨ Features

- 🤖 AI-generated project reports
- 📄 PDF Export
- 📊 Interactive Dashboard
- 🌌 Modern Glassmorphism UI
- 📈 Analytics Charts
- ⭐ Activity Constellation
- 📜 Report History
- ⚙️ Settings Page
- 👀 Live Report Preview

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini AI
- Plotly
- Altair
- Pandas
- NumPy
- FPDF
